分集节奏（短剧体裁建议）：
- 开篇 ~4 秒承担钩子职能：用强冲击 / 悬念 / 危机切入，避免介绍性远景。
- 中段每 ~15 秒宜安排一次转折点（动作转折 / 情绪反差 / 关系撕裂 / 异常事件），
  通过画面权重和景别变化呈现，避免长段平铺。
- 末镜停在情绪极致瞬间，shot_type 倾向 Close-up / Extreme Close-up，
  给观众留下回看的钩子。

夺注意力节奏（更细粒度的叙事状态变化节拍，非镜头时长）：
- ~2 秒宜出现第一处异常（不正常的一瞬），~6 秒宜让钩子成形（观众明白这是什么故事、
  开始想继续看下去），此后每 ~8-10 秒宜有一次真实变化（新问题 / 新威胁 / 策略转向 /
  关系变化 / 付出代价 / 不可逆的行动）——这条节拍衡量的是叙事状态的变化频率，
  不是分镜或镜头本身的长度。
- 时间轴密度宜「前密、中疏、后密」，避免均匀分布。
- 台词句子宜短，短到适配硬字幕；连续纯对白的分镜不超过 2 个。
- 开篇是**选出来**的，不是时间线上最早发生的事件；忌用「介绍环境 / 角色自我介绍 /
  走路赶路 / 寒暄问候」开场。背景设定信息应在冲突已经发生时顺带交代，不单独铺垫。
  开篇许下的承诺，正片须以同等或更强的强度兑现。
- 遮名测试：遮住角色姓名，仍能凭语气 / 用词 / 行事策略认出是谁在说话。
- 每句台词宜同时做两件事（表面话题 + 潜台词 / 冲突），沉默也是一种有功能的行动。
- 结尾宜给观众留一件「可做的事」（想重看、想分享、想争论、感到担忧、追下一集）；
  知识类内容收在关键洞见处；不索取点赞或关注。
