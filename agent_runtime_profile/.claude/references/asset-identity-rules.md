资产身份锚定规则（角色 / 场景 / 道具）：写 description 前先读完本节，`analyze-assets` 子智能体
Step 3 抽取三类资产、以及后续对已有资产 description 的修订都按本节口径执行。

## 角色（character）

- **身份锚点必须写死**：肤色、发色、瞳色三项缺一不可——不写，生图模型每次会随机分配，导致
  同一角色跨图变脸。另外须写：感知性别与年龄、脸型、五官特征、发长/发型/发质、体型/轮廓、
  服装（款式、年代、材质、颜色）。**鞋履必须写**；配饰只在有助于识别时写。
- **稳定描述中禁止出现**：表情、姿势、动作、背景/环境、正在手持的道具、叙事性语句、含糊词
  （"或"、"可能"、"大概"）、抽象的非视觉形容词（"气质强大"、"成熟稳重"）——这类信息必须翻译成
  看得见的轮廓/服装/材质/配饰，不能直接写抽象词。
- **非人类角色**：从物种/形态/表面材质/关键器官描述，不套人类模板硬写五官身材。
- **状态变化不是改写本体描述**：受伤、换装、剃发等属于新的衍生形态（`@[角色/衍生]`，见本文件
  所属项目的衍生机制），不能覆盖或稀释本体描述里的身份锚点。

## 场景（scene）

- 把笼统地名（如"一座花园"）具体化为一个稳定空间：写清墙面/地面/天花板/边界、尺度与进深关系。
- 至少给出 **3 个稳定的空间锚点**（可辨认的固定物或结构），锚点周围留出空地供后续人物站入。
- 不画标签、箭头或占位符。

## 道具（prop）

- 只写道具本体的静态视觉信息：结构、轮廓、数量、材质、颜色、表面处理与磨损痕迹。
- 不写用途、剧情、握持它的手/桌面/房间、运镜或光线——这些属于分镜正文，不属于道具资产图。
