分镜-视频连续性与运镜规则：写 image_prompt / video_prompt 前先读完本节，`prompt_authoring`
（drama 的 `build_drama_prompt`、narration 的 `build_narration_prompt`、参考生视频的
`build_reference_video_prompt`）都按本节口径执行。

## 1. 每个分镜的内部状态表（不作为字段输出，只在写作时内心维护）

写每个分镜前，先在心里维护一张状态表：
- 角色：身份、服装、身体状态（是否受伤/喘息/湿透等）、位置、身体朝向、目光落点。
- 道具：谁持有、位置、开/关/亮/灭等状态。
- 场景：时间、光线、天气、主要结构。
- 已经向观众交代过的信息。
- 仍在持续的声音（画外音/环境音是否还在响）。

**分镜 N 的入口状态 = 分镜 N-1 的出口状态 + 本分镜的新变化。** 状态只能向前推进：一个已经
完成的动作（拿起了、转身了、站起来了、开门了、说完一句台词了），下一个分镜要从「已完成」
的状态接着往下写，不能因为换了景别就把同一个动作再演一遍。

## 2. 参考图只锁定身份

角色 / 场景 / 道具参考图锁定的是「这是谁 / 这是什么」及其设计，不能让本分镜继承参考图（资产
定妆照）里的正面居中构图、中性站姿或直视镜头——本分镜的构图、姿态、光线由本分镜的叙事需要
决定，不是照抄参考图的姿态。每张用到的参考图只服务一个目的（锁定角色身份 / 锁定场景结构 /
锁定关键道具 / 承接上一分镜的构图），不要一张参考图身兼数职。

## 3. 表演纪律

- 动作文本里禁止出现情绪形容词或内心独白（"愤怒地"、"她很紧张"、"心里五味杂陈"）——把情绪
  翻译成看得见的身体变化：呼吸、手、下颌、肩膀、步态、目光停留的时长。
- 表演幅度宜克制、不宜夸张：视频生成模型倾向于把动作演过头，宁可写小动作也不要写大动作。
- 情绪强度写进动作本身（摔门、踹椅子），不要靠副词堆叠（"狠狠地"、"猛烈地"）。
- 反应分层推进：僵住 → 确认 → 释放，每个分镜只演一层，不要在一个分镜里演完全部三层。
- 每个分镜最多一次情绪转折，且这次转折必须由分镜内部一个看得见的事件触发，不能无来由地
  切换情绪。

## 4. 运镜

- 每个分镜承担一个明确的叙事职能：建立空间 / 推进动作 / 展示反应 / 揭示信息 / 改变关系 /
  定格节拍——写之前先想清楚这个分镜为什么存在。
- 有角色出场的分镜要写清楚：景别、镜头与角色的相对位置、主体在画面中的位置、身体朝向、
  目光落点，以及**一个**主要运镜方式；不要在一个分镜里塞两种互相矛盾的运镜。
- 同一时空内的分镜之间用直切；只有发生时间跳跃或情绪转折时才使用有物理意义的转场
  （不是叠化/淡入淡出这类后期特效转场，见第 6 条固定约束）。

## 5. 视频提示词里的台词与声音

- 说话人必须在画面内，或已经通过前文明确交代画面外说话人是谁。
- 台词必须能在本分镜的时长内说完，不要写一句需要更长时间才能念完的台词。
- 只写此刻真实能听到的声音（台词、动作音效、环境音），用具体的质感词描述（不是"有声音"，
  而是"木门吱呀作响"）；不写背景音乐；同一段环境音不要在每个分镜里重复触发一次，
  已经在响的环境音延续即可，不需要每个分镜都重新交代一遍。

## 6. 固定反向约束

画面 / 视频生成的反向提示词固定包含：字幕、标题、水印、拼贴、分屏、多余人物、人物直视镜头
（除非剧本明确要求打破第四面墙）；视频额外固定包含 BGM、镜头之间叠化/交叉溶解/淡入淡出、
前后画面透明重叠——这些由 `lib.prompt_utils.STORYBOARD_AVOID_ITEMS` /
`lib.prompt_utils.VIDEO_AVOID_ITEMS` 统一追加到每条最终提示词末尾，写作时不需要在正文里
重复声明，但也不要写出与这些约束矛盾的内容（如在 action 里主动写「叠化到下一个画面」）。
